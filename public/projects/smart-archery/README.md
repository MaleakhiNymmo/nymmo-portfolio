# SmartArchery Assets Folder

Simpan file gambar untuk project **SmartArchery** di folder ini:

1. **`cover.png`** (atau `cover.jpg`)
   - Rekomendasi rasio: 16:9 atau 4:3 (resolusi ideal 1200x800 atau 1920x1080).
   - Menampilkan screenshot aplikasi Android SmartArchery saat mendeteksi postur panahan (dengan bounding box / keypoints pose skeleton) atau mockup smartphone.

2. **File Tambahan (Opsional)**
   - `architecture.png`: Diagram alur sistem (Kamera HP -> YOLO11 Pose -> Kalkulasi Sudut -> Database Pelatih).
   - `detection_sample.png`: Contoh deteksi sudut postur saat atlet drawing & anchor.
   - `coach_portal.png`: Tampilan layar dashboard atau laporan evaluasi atlet untuk pelatih.
